# 🕒 QP Date and Time

A lightweight, minimal, and lightning-fast web utility designed to handle, format, and display real-time date and time data. Deployed seamlessly on Vercel.

🔗 **Live Demo:** [qp-date-and-time.vercel.app](https://vercel.app)

---

## 🚀 Features

- **Real-Time Display:** High-precision tracking of local time.
- **Clean UI:** Minimalist and responsive design that works perfectly on both desktop and mobile devices.
- **Lightweight Performance:** Built with optimization in mind, ensuring instant load times.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Hosting & Deployment:** [Vercel](https://vercel.com)

---

## 💻 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd qp-date-and-time
   ```

3. **Open the project:**
   Simply open the `index.html` file in your favorite web browser, or use a local development server like Live Server in VS Code.
